# Carrosséis @lucaslino.fisio

Artes e gerador dos carrosséis de fisioterapia baseada em evidências do @lucaslino.fisio.

- `fila.json`: agenda (seg 19h, qua 12h, sex 12h) e status de cada post
- `carrosseis/`: uma pasta por post (spec, legenda, slides em JPEG)
- `pipeline/`: gerador (`build.py`), ilustrações em código e assets
